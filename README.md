# Portfolio de Thomas Gerard

Site statique personnel du dépôt [`ThomasG0342.github.io`](https://github.com/ThomasG0342/ThomasG0342.github.io).

## Contenu

Le portfolio est réalisé en HTML et CSS, sans compilation ni dépendance. Modifiez
`index.html` pour mettre à jour le profil, les expériences, projets et coordonnées.
Le numéro de téléphone et l’adresse postale ne sont pas publiés. Aucun PDF de CV
n’a été fourni : la page reprend les informations communiquées, et le fichier PDF
pourra être ajouté séparément si souhaité.

## Publication avec GitHub Pages

Le workflow `.github/workflows/pages.yml` déploie le site sur GitHub Pages après
chaque push sur `main` et peut également être lancé depuis l’onglet **Actions**.
Lors de la première configuration, ouvrez **Settings → Pages** et sélectionnez
**GitHub Actions** comme source de publication. L’URL publique sera affichée par
GitHub lorsque le déploiement aura réussi.
